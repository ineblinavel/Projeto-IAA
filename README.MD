# Detecção de Árvores Urbanas com YOLO-MS

Este projeto aplica o modelo YOLO-MS na tarefa de detecção de copas de árvores individuais em imagens urbanas de alta resolução, utilizando Deep Learning e validação cruzada.

## Base do Projeto

O trabalho é baseado no benchmark:

> Zamboni et al. (2021) - *Benchmarking Anchor-Based and Anchor-Free State-of-the-Art Deep Learning Methods for Individual Tree Detection in RGB High-Resolution Images* ([link](https://doi.org/10.3390/rs13132482))

## Objetivo

Avaliar o desempenho do modelo YOLO-MS, uma arquitetura moderna para detecção de objetos, e compará-lo com os modelos testados por Zamboni et al., utilizando a mesma base de dados e métricas.

## Notebook

O treinamento é realizado diretamente em um notebook do Google Colab. Devido à limitação de tempo de execução do Colab, os resultados gerados (como pesos, logs e métricas) são automaticamente salvos no Google Drive do usuário que executa o notebook. Para facilitar o acesso, também disponibilizamos uma pasta com os resultados já obtidos.

## Dataset
Devido ao tamanho do conjunto de dados utilizado, os arquivos estão disponíveis na seção Releases do repositório no GitHub, facilitando o download sem a necessidade de reprocessamento.
